# B-2 基准：逻辑型漏洞子集的 LLM 语义推理 vs 确定性基线

> 日期：2026-08-27 ｜ 数据：`dataset.jsonl` 干净版 28 样本（剔除 Rust 修复污染 2 CVE）
> 模型：Ollama `qwen2.5-coder:7b`（temperature=0）｜ 基线：CPGEvidence / StructuralHeuristic / CodeQLBaseline / ConfigSig
> 提交：`68f2b90`（TarSlip 强化）＋ 本报告对应 prompt v2（SYSTEM 明确「无流≠无漏洞」）
>
> ⚠️ **协议修正（2026-08-28）**：本报告为 28 样本、**含公告摘要**的历史记录。
> 主结果协议已改为无摘要（标签泄漏修复）——54 版本无摘要下 LLM 全局 F1=0.409、
> logic 子集 0.231，**未再高于确定性基线**（详见 B3-消融与互补性报告.md §6）。
> 本报告的"LLM 首次反超"结论依赖摘要线索，仅供历史参照，不得作为当前立论依据。

## 1. 问题

「上下文增强」假设（LLM 消费 CPG 证据后优于确定性解析器）此前在真实 CVE 上未获稳定证据。
B-2 目标：在**逻辑型漏洞子集**（鉴权/走私/信息泄露/输入校验——不产生数据流，CPG taint 天然为空）
上检验 LLM 语义推理是否提供确定性基线之外的判别能力。

## 2. 方法

- 分组：`taint`（可污点类 CWE-022/918，8 样本）vs `logic`（其余 CWE，20 样本）。
- 上下文：`code` 模式 = 源码节选（taint 锚点块优先，≤6000 字符）+ CPG 污点切片 + 公告摘要。
- prompt v2 关键改动：SYSTEM 增加判断原则——「污点切片只覆盖数据流型漏洞；切片为空不代表目标安全；
  逻辑型漏洞不产生数据流，应以公告摘要为线索核查功能点是否缺失安全控制」。

## 3. 结果（code/both 模式）

| 指标 | prompt v1 | prompt v2 | CPGEvidence（不变） |
|------|-----------|-----------|---------------------|
| 全局 F1 | 0.500 | **0.519**（P=0.538 R=0.500） | 0.480 |
| logic 子集 F1 | 0.444 | **0.471**（P=0.571 R=0.400） | 0.400 |
| taint 子集 F1 | 0.600 | 0.600 | 0.600（并列） |

- v2 改善机制：误报下降（FP 7→6，如 53505_fixed 修复）、部分逻辑样本从「自信错判 benign」转为「诚实 abstain」。
- **LLM 在全局与 logic 子集上首次稳定高于确定性基线**（0.519 vs 0.480；0.471 vs 0.400）。

## 4. 定性证据（rationale 抽取）

### 4.1 LLM 语义推理成功（独对样本）
| 样本 | CWE | 摘要线索 | LLM rationale |
|------|-----|----------|---------------|
| 53505_vuln | 400 | thumbor proportion filter 无界 post-transform resize | "allows unbounded post-transform resize, leading to potential remote DoS" |

确定性基线（含 CPGEvidence）在 53505_vuln 上全部判 benign（无数据流证据）；LLM 靠摘要+源码语义判 vulnerable。修复 diff 仅一行守卫 `if value <= 0 or value > 1.0: return`——纯逻辑缺陷，无数据流可表达。

### 4.2 漏报模式（v1 prompt 系统性缺陷，v2 缓解）
7 个逻辑型 vuln 在 v1 下全部判 benign，rationale 统一为「未检测到未信任输入到达接收器」——
**LLM 把「无 taint 流」等同于「无漏洞」**。v2 修正提示后，该类样本转为 abstain 或按摘要复核，
误报率下降、诚实弃权增加。

### 4.3 误报模式
LLM 在 6 个 fixed 样本上误报 vulnerable，两类成因：① 有 taint 流时过度信任切片（53502_fixed）；
② 摘要描述与源码错配时过度警觉（67435_fixed，rationale 将 CWE-200 错标为 CWE-022）。

## 5. 边界与结论

- LLM 的独对证据目前仅 53505 一类（简单逻辑缺陷）；复杂语义（TarSlip 安全包装识别、请求走私）
  7B 模型仍失败或 abstain。
- temperature=0 下跨运行仍观测到单样本判定抖动（单样本实验 54785/71554 转 TP 未在全量复现），
  指标差异在 1-2 样本量级，结论方向（LLM ≥ 确定性基线于 logic 子集）需多 seed 验证。
- **贡献点**：LLM 语义层在逻辑型子集提供确定性基线之外的判别（0.471 vs 0.400），
  与 CPG 数据流层（taint 子集 0.600 并列）构成互补；prompt 的「无流≠无漏洞」原则是上下文增强的
  必要组件。14B 及以上模型受机器内存（17GB）限制，列为后续工作。（⚠️ 更新：14B 已于 2026-08-28 在本机跑通——`results_14b.csv` + `B3-消融与互补性报告.md` §6.4：14B 全局 F1=0.531、逻辑域 0.323→0.545，CPG 增益缩至 +0.033，呈规模-证据替代趋势。本条已被后续实验 supersede。）
- **2×2 隔离消融**（见 B3-消融与互补性报告.md，3 seed 零方差）：有码条件下 CPG 增益 +0.064
  （0.455→0.519，召回 +0.143），代价为 fixed 误报 +3（修复未消除数据流样本跟随 taint）；
  源码增益 +0.455（无 taint 条件）。CPG 是增益层而非主判定层，与源码互补。
