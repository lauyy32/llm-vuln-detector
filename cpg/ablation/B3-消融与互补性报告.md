## 3. 静态工具边界（absence-based CWE）

CWE-862/863/639（鉴权缺失/IDOR）属「基于缺失」漏洞：源码中无「缺失点」可锚定，

## 4. 结论（3 seed 完全一致，零方差）

### 4.1 增益分解（LLM，code 模式，全局 F1）

| 设置 | F1 | P | R |
| --- | --- | --- | --- |
| D 无码无taint（request） | 0.000 | — | 0.000 |
| C 无码+taint | 0.480 | 0.545 | 0.429 |
| B 有码无taint | 0.455 | 0.625 | 0.357 |
| A 有码+taint | **0.519** | 0.538 | 0.500 |

- **CPG（taint）增益（有码条件下）**：A − B = **+0.064**，来源是召回 +0.143（0.357→0.500）
  —— CPG 污点证据把 LLM 的漏报显著压下去，代价是精度 -0.087（0.625→0.538）。
- **源码增益（无 taint 条件下）**：B − D = **+0.455**（召回 0→0.357）——源码是判别基础。
- **源码增益（有 taint 条件下）**：A − C = +0.039。
- **taint 增益（无码条件下）**：C − D = +0.480——单独 taint 证据（0.480）甚至高于单独源码（0.455）。

### 4.2 回答「CPG 是否为正确解法 / 增益是否显著」

- **CPG 是正确解法（作为增益层，而非主判定层）**：在源码已存在时，CPG 污点证据带来
  +0.064 F1 / +0.143 召回的可复现增益；单独 taint（0.480）不输单独源码（0.455）。
  证据链（空码 0.000 → 加 taint 0.480 → 加码 0.519）说明 taint 与源码是**互补输入**，
  而非可互相替代。
- **增益幅度**：+0.064（28 样本）为实质增益但非「显著」级——归因于语料中 taint 可命中的
  样本占比（8/28）；增益集中在 taint 子集（50558/53502/67424 等数据流样本）。
  对「CPG 显著增益」的更强论证需扩充 taint 覆盖 CWE 与样本量。
- **诚实边界**：LLM 的判别力在逻辑子集（无流）上仍依赖摘要+源码语义（0.471 vs 确定性
  基线 0.400）；CPG 对逻辑型漏洞无贡献（无流可提取）——这正是互补性立论：
  **CPG 覆盖数据流域，LLM 语义覆盖逻辑域，合并 0.519 为当前上限**。

- 互补性结论：CPG 提取层（确定性 0.600 taint）与 LLM 语义层（0.471 logic）

### 7.8 最终结论

> **74 样本复验（2026-08-29，§6.0）**：以下 7 条结论在 74 CVE / 148 版本下全部不变——
> LLM 0.321 vs CPGEvidence 0.330（差值 CI [-0.041, 0.008]，收窄 55%）、
> B 组 LLM 仍全漏（A−B=+0.321）、Bandit 对比、B-2 语义补全结论均成立。
> 全局 F1 绝对值回落系 logic 类样本占比上升（42→108 版本）所致，方向不受影响。

1. **CPG 是增益层且为判别必要条件**（数据流域）：无摘要下 A−B=+0.409
   （54 样本；74 样本 +0.321，B 组 LLM 仍全漏），带摘要时 +0.133——摘要掩盖了部分 CPG 增益。
2. **LLM 与确定性解析器相当（无泄漏下）**：全局 F1 0.409 vs 0.435（54 样本；
   74 样本 0.321 vs 0.330），bootstrap 差值 CI [-0.091, 0.000]（74 样本 [-0.041, 0.008]）、
   LLM 高于 CPG 比例 0.0%（74 样本 24.2%）——未优于确定性解析器；
   带摘要时的"99.7% 显著"来自摘要泄漏，已撤销该主张。
