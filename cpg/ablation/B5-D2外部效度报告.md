# B5 D2 外部效度报告（P0-3）

> 关联任务：P0-3 Devign 公开基准外部效度校验
> 运行：2026-09-03 · LocalLLMScorer qwen2.5-coder:7b · temperature=0 · 本地 Ollama
> 数据源：HuggingFace `DetectVul/devign` test split（2732 样本，parquet 落盘
> `cpg/benchmarks/devign/devign_test.parquet`，转 `devign_test.json` 2571 条）
> 产物：`cpg/ablation/seeds/v9_d2_devign/`（results.csv + summary.md + raw_llm_responses.jsonl）

## 1. 设计纪律（重申）

- D2 与 D1「补丁边界判别」是**不同 claim**，不混用；D2 仅回答「LLM 打分器在通用函数级
  vuln 检测上有无判别力」，作为本课题核心 claim 的**外部效度 / 合理性对照**。
- Devign 为函数级**独立样本**（非 vuln/fixed 配对）→ McNemar 配对检验不适用，
  退化为独立样本 BA / MCC / F1 + 平凡基线对照。
- 平衡采样（每类 250）→ 平凡「全判 vulnerable」基线 F1=0.667，暴露 F1 陷阱（与 D1 同口径）。
- 仅跑 LLM 类（LocalLLMScorer）；C/C++ CPG Scorer 出范围（CodeQL-python 仅覆盖 Python）；
  PublishedLLMBaseline 需 API Key，依规递延。

## 2. 结果

| 指标 | LLM 打分器 | 平凡基线（全判 vulnerable） |
|------|-----------|----------------------------|
| 样本（决定 / abstain / 总） | 88 / 412 / 500 | — |
| 覆盖率（非 abstain） | **0.176** | — |
| 灵敏度 Sensitivity | 0.436 | — |

| 平衡准确率 BA | **0.473** | 0.500 |

## 3. 判读

- **F1=0.425 ≤ 平凡基线 0.667**：在 50% 正类平衡语料上，单独 F1 再次失效，与 D1 同一口径；
- **MCC=−0.054（< 0，接近随机）**：LLM 打分器在 Devign 通用函数级检测上**无判别力**，
  略低于随机（负向来自灵敏度/特异度失衡）；
- **BA=0.473 < 0.500**：同样低于随机猜测；
- 覆盖率仅 0.176（412/500 abstain）：C/C++ 函数级代码触发大量弃权（打分器为语言无关但
  对长函数/复杂结构保守弃权），进一步压缩可用信号。

## 4. 与立论的关系

- 外部基准上 LLM 打分器判别力**接近/低于随机**，与 D1「补丁边界判别近随机」
  （BA∈[0.500,0.518]、MCC∈[0,0.047]）**方向一致**——本课题的核心负面结果在
  独立公开基准上可复现，增强结论的外部效度。
- 这**不是**「CPG 互补 / 必要」的证据（D2 不含 CPG）；它界定了「纯 LLM 函数级检测」
  的能力边界，反衬本课题将问题收敛到「补丁边界 + CPG 证据」的必要性。
- 论文须明确：D2 的负面结果是**方法论自洽**的一部分（评测/外部效度贡献），
  非性能宣称。

## 5. 可复现命令

```bash
# 1) parquet -> json（需 pyarrow）
PYTHONPATH=$LIBDIR python -c "
import pyarrow.parquet as pq, json
t=pq.read_table('cpg/benchmarks/devign/devign_test.parquet')
out=[{'func':(r.get('func') or r.get('function') or r.get('code')).strip(),
      'target':int(r['target']),'project':r.get('project') or 'unknown','cwe':None}
     for r in t.to_pylist()
     if isinstance(r.get('func') or r.get('function') or r.get('code'),str)
     and 20<=len((r.get('func') or r.get('function') or r.get('code')).strip())<=6000
     and r.get('target') in (0,1)]
json.dump(out, open('cpg/benchmarks/devign/devign_test.json','w',encoding='utf-8'), ensure_ascii=False)"
# 2) 跑 D2
python cpg/ablation/run_d2_devign.py --data cpg/benchmarks/devign/devign_test.json \
  --out-dir cpg/ablation/seeds/v9_d2_devign --model qwen2.5-coder:7b --n-per-class 250 --seed 42
```
