# P1-12：placebo 三臂的前沿模型 spot-check（DeepSeek-v4-flash，2026-09-05）

> 目的：主协议锁定本地 2024-cutoff 模型（qwen2.5-coder 7B/14B，时序隔离记忆化污染）。
> 评审风险点是"结论是否 2024 小模型特异"。本实验把**全篇唯一 p<0.01 的阳性锚点**
> （placebo 三臂）在前沿 API 模型上做一次**加法式**抽查——不动任何冻结数字，
> 结果只进附录小节。
>
> 预注册解释分支：① placebo 拒绝率复现 → 阳性锚点升为跨世代证据；② placebo 翻车 →
> "读补丁"能力为世代特异，结论收窄；③ real 臂 benign 率远高于 53% → "漏判真实修复"
> 边界移动，须改写叙事。

## 1. 协议

- 脚本：`patch_verify_control.py --backend openai`（本次新增 OpenAI 兼容后端；
  与 Ollama 臂**同 system prompt、同源码、同 taint 切片、同 temperature=0**）。
- 模型：deepseek-v4-flash（API，2026 世代）；`--dataset cpg/dataset_d1.jsonl`，
  CPG 双标记子集有效 n=15（49257/67428 不在 D1，与主协议口径一致）。
- 规模：15 CVE × 3 臂 × 3 轮 = 135 次调用；raw 全量落盘
  `.work/patch_verify_control_deepseek_raw_r{1,2,3}.jsonl`。
- 污染前提：该模型已通过灵敏度验证的记忆化探测（GT0 §5：阳性 4/5，阴性 85/85
  UNKNOWN），且 placebo/shuffled 臂的 diff 为合成/移植，记忆化通道天然微弱。

## 2. 结果

| 轮次 | real benign | placebo benign | shuffled benign | real−placebo 差 |
|---|---|---|---|---|
| r1 | 6/15 | **0/15** | 0/15 | +0.400 |
| r2 | 8/15 | 1/15（53502） | 0/15 | +0.467 |
| r3 | 9/15 | **0/15** | 0/15 | +0.600 |
| **池化** | **23/45（51%）** | **1/45（2.2%）** | **0/45（0%）** | — |

对照（本地，n=15）：7B real 8/15 / placebo 0/15 / shuffled 3/15；14B real 8/15 /
placebo 0/15 / shuffled 0/15。

逐轮 McNemar（real vs placebo，不一致对 b/c）：r1 b=6/c=0 → p=0.0156；
r2 b=8/c=1 → p=0.0195；r3 b=9/c=0 → p=0.0020（均为单侧精确二项；
三轮非同一样本，只逐轮报、不池化 p）。

## 3. 发现

1. **阳性锚点跨世代复现成立（分支①）**：placebo 臂正确拒绝 44/45（97.8%），
   三轮逐轮 McNemar 均 p<0.05；shuffled 臂 0/45 被骗（优于 7B 的 3/15）。
   "模型能识别装饰性/无关改动"不再是 2024 小模型特异现象。
2. **real 臂良性判定率复现**：23/45（51%）≈ 7B/14B 的 53%——"前沿模型同样
   漏判约一半真实修复"，RQ1 负面结论的规模稳健性增强。
3. **率复现 ≠ 实例复现**：r2 中 real-benign 集合与 7B 仅 5/8 重合
   （交集 50181/53598/59890/70491/73498）；DeepSeek 独有判对 54706/54707/67424。
   即"判对哪些修复"是模型特异的，"判对多少"是稳定的——正文措辞须限定在率上。
4. **新行为观察（API 侧）**：空响应 37/135（27%），且逐臂不对称
   （real 21/45 > shuffled 11/45 > placebo 5/45）——real 臂含真实漏洞源码，
   疑似触发服务端安全过滤。空响应**不计被骗**（未输出 benign），按独立类别申报。
   与 CodeLlama 结构化任务弃权（42/45）并列为"模型可得性"边界。

## 4. 局限

- API 残余非确定性：temp=0 下三轮 real 臂 benign 6/8/9 仍漂移（漂移本身即数据）；
  "温度 0 确定性"表述仅属本地臂（GT0 §5.6 口径）。
- 单一 API 模型、单 prompt 形态；结论为 spot-check 级，不外推为前沿模型全量结论。
- 网络中断 3 次（VPN 502/超时），以幂等重跑补齐；三轮最终均完整（15 CVE×3 臂），
  完整性与中断过程如实记录。

## 5. 对论文的影响

- 主协议数字**零改动**；本结果进附录小节 "frontier spot-check"，用于回应
  "模型代表性"质疑。
- 摘要/正文可加一句：阳性锚点在 2026 世代 API 模型上复现（placebo 拒绝 44/45），
  实例级判别集合仍模型特异。
