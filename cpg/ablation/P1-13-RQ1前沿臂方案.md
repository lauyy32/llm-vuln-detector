# P1-13：RQ1 前沿臂方案（DeepSeek 接入 82 对主协议判别）

> 起因：P1-12 v2 的附录证据显示前沿模型在 placebo 子集近乎完美（45/45 拒绝、
> real 89%），而 RQ1 主协议（82 对 vuln/fixed 配对判别）此前零前沿覆盖——
> "你自己附录都暗示前沿不随机，主负面结果凭什么外推"成为迁移后的新攻击面。
> 本实验正面回应：把 2026 世代 API 模型接入主协议，跑同上下文、同口径的
> 配对判别。无论结果方向，论文都因此更严密。
>
> **解释分支（先于跑批确定，2026-09-05）**：
> - **A. 前沿也近随机**（判别正确 ≤5/82 或 McNemar 不显著）→ 主负面结果升格为
>   **跨世代结论**，标题/摘要不动，附录加一行。
> - **B. 前沿显著判别**（判别正确 ≥10/82 且逐轮 McNemar p<0.05）→ 叙事转为
>   **"能力边界"**：近随机是小模型 + CPG 证据链现象，前沿模型恢复判别力；
>   标题/摘要/§4 按此重写（2-3 天），RENE 适配性不受损（仍是严格受控的
>   负面/边界结果，且含机制解释）。
> - **C. 中间态**（判别正确 6-9/82 或 CI 跨阈）→ 报为 inconclusive，主张仍收窄
>   为本地模型口径并在 Threats 披露前沿信号不确定。

## 1. 协议（与冻结主协议逐项对齐）

| 项 | 冻结主协议（v9） | 本臂 |
|---|---|---|
| 语料 | dataset_d1.jsonl 85 对，配对分析在完整对 n=82 | **同** |
| 模式 | --modes code | **同** |
| 上下文 | code_text + CPG 污点切片（同一切片管线） | **同**（同 run_ablation 同一 ctx 构造） |
| 温度 | 0 | **同** |
| 判定器 | LocalLLMScorer（qwen 7B/14B） | **APILLMScorer（deepseek-v4-flash）** |
| 输出预算 | num_predict=512（本地） | max_tokens=8192（reasoning 模型教训，P1-12） |
| 轮次 | 1（本地确定性） | **2 轮**（API 漂移观测，P1-12 已证漂移存在） |
| raw | raw_llm_responses.jsonl | raw_api_llm_responses.jsonl（同机制） |
| 统计契约 | paired_metrics.py --check（BA/MCC/平凡基线/单侧精确 McNemar） | **同** |
| 污染前提 | 时序论证（本地 2024 cutoff） | 探测已验证（GT0 §5：灵敏度 4/5 + 阴性 85/85 UNKNOWN） |

## 2. 规模与成本

- 85 对 × 2 版本 = 170 次调用/轮；2 轮 = 340 次。
- deepseek-v4-flash 输入约 6-10k tokens/次；预算 < 10 美元。
- 预计 1.5-2.5 小时/轮（VPN 抖动下 API 失败自动转 abstain，见 §3 处置）。

## 3. 失败处置（先于跑批确定）

- 单轮 abstain 率 >20% → 该轮作废重跑（网络级故障）；
- abstain ≤20% → 保留并在报告中按独立类别申报（不计入判别正确/错误），
  判别统计在"双端非 abstain"的完整对上进行（与主协议 pair-completeness 同口径）。

## 4. 产物

## 5. 结果（2026-09-05 深夜跑批；2026-09-06 按严格弃权口径勘正）

> **口径勘正声明（2026-09-06）**：本节初版存在三处问题，已全部勘正——
> ① 前沿 vs 本地的 McNemar 是**混合规则**比较（前沿 strict、本地 lenient）；
> ② 弃权账目把 8 次网络异常误记为 4、"真弃权率"误记为 97%；
> ③ 未申报判别判定对**弃权映射规则敏感**。
> 权威复算脚本 `cpg/ablation/.work/strict_recompute.py`（全部数字可重算）。
> **口径裁决**：采用 strict（判别 = vuln 显式 vulnerable AND fixed 显式 benign，
> abstain 不记任何一侧）——依据是本方案 §3"abstain 不计入判别正确/错误"的
> 预注册承诺与本课题无假良性纪律（abstain 不得记为正确 benign，D5）。

### 5.1 主表（strict 口径，完整对 n=82，与冻结主协议同门禁）

| 判定器 | 判别正确（strict） | 双侧 95% CP-CI | 单侧 95% 上界 | answered-only BA / MCC |
|---|---|---|---|---|
| 本地 7B（v9） | **2/82** {61539, 67435} | [0.3%, 8.5%] | 7.5% | 0.514 / +0.035（142/164） |
| 本地 7B（v10 复跑） | 2/82（同集） | 同左 | 同左 | 0.523 / +0.055（141/164） |
| 本地 14B（74 集） | **0/74** | [0.0%, 4.9%] | 4.0% | — |
| 前沿 DeepSeek r1 | 7/82 {12482,13769,53502,53505,61539,67424,73498} | [3.5%, 16.8%] | 15.4% | 0.610 / +0.219（86/164） |
| 前沿 DeepSeek r2 | 7/82 {49852,53502,53505,54706,61539,61632,67425} | 同左 | 同左 | 0.564 / +0.129（90/164） |

- **跨轮复现**：计数稳定（7/82 = 7/82），实例漂移大——两轮均判别仅
  {53502, 53505, 61539}（3/7），与本地 v8→v9 漂移同型。
- **对称 strict McNemar（前沿 vs 本地）**：前沿独有 6、本地独有 1（67435），
  b=6/c=1，单侧精确 **p=0.0625**（两轮同值）。
  （勘正：初版 0.1445 系混合规则产物——前沿 strict 对本地 lenient；
  另注意与已作废的"14B lenient 4/74 p=0.0625"撞数，行文须区分。）
- **分支判读（2026-09-06 二次勘正）：结果落入预注册 A/C 重叠区**（A 的
  "McNemar 不显著"析取项与 C 的"6-9/82"区间同时命中），原规则**无法唯一
  判定**，实质 **inconclusive**。且按原协议"单轮弃权 >20% 作废"条款，
  两轮结果不进入确认性推断，**降级为探索性结果与敏感性分析**；
  不声称事后解释恢复了原预注册有效性（deviation D1/D2 见 §3 与 P1-16 A6）。
- **三个 p 值不可混写（2026-09-06 补）**：① 前沿 vs 本地判别**集合**比较
  p=0.0625（b=6/c=1）；② 前沿**自身方向检验**（仅双端作答对）：r1 26/82 对、
  7 正/2 反 → p=0.0898；r2 36/82 对、7 正/3 反 → p=0.1719；③ 本地主协议
  各 p（0.25 strict / 历史 0.3125 lenient）。三者对象不同，附录分列。
- **14B 旧"全研究最佳"作废**：lenient 口径的 4/74 经逐行核验**全部 4 例为
  弃权辅助**（fixed 端 abstain 被宽松映射为非 vuln），strict 下为 0/74。
  冻结文档族（README 里程碑/effect_size/ST4）已级联勘正。

### 5.2 弃权行为（账目勘正后）

- version 级 abstain：r1 82/170、r2 77/170（合计 159）。
- **故障类弃权 = 11**（网络异常 8：r1a 3/r1b 4/r2a 1/r2b 0 + 空响应 3：r1a 1/r1b 2），
  故障率 11/340 = 3.2%。（2026-09-06 二次勘正：原协议"单轮弃权 >20% 作废"未区分
  故障类型，两轮总弃权 48%/45% 按字面即触发作废——本结果已降级为**探索性/
  敏感性分析**，见 §5.1 判读重标与 P1-16 A6；"按故障子集有效"是修正口径，
  不恢复原预注册有效性。）
  （勘正：初版"网络异常 4"只数了 r1b 一片；"97% 主动弃权"亦误。）
- **真弃权 = 148/159 = 93.1%**——模型主动慎判（rationale 多为"代码节选未
  展示足够证据"），对照本地 7B v9 弃权 22/164、v10 弃权 23/164。
  前沿模型呈"低覆盖、高慎判"模式；answered-only BA 必须与覆盖率同句出现，
  不得单独引用（选择效应）。
- raw schema 缺口：raw_api_llm_responses.jsonl 无 version 字段，无法与
  results.csv 逐行 join；已在 scorers.py `_log_raw` 补 version 字段（下批生效）。

### 5.3 规则敏感性申报（主动披露，否决反事实）

- **lenient 反事实**（abstain→非 vuln 宽松映射）：r1 判别 19/82（辅助 12），
  vs 本地 lenient 3/82 的 McNemar b=17/c=1、p=7.25e-5（显著且 ≥10 → 触发 B 分支）；
  r2 判别 9/82、b=7/c=1、p=0.0352。**lenient 下两轮分支互不一致（B/C 漂移），
  本身即说明该规则不稳定。**
- **裁决**：strict 唯一自洽——预注册承诺 + 无假良性纪律双 mandate，且 strict
  是唯一跨轮稳定的读法（两轮计数均 7/82）。lenient 数字在此公开，供审稿人复算对照；
  本课题一切结论仅用 strict。（判读层级见 §5.1：A/C 重叠- inconclusive、探索性结果。）
- **§3 预注册措辞勘误**："判别统计在双端非 abstain 的完整对上进行"字面可误读为
  受限分母；实际执行为分母保留 82、弃权对不贡献判别事件（更保守），
  与冻结主协议 pair-completeness 口径一致。

### 5.4 解读（勘正后）

1. **主负面结果更硬**：strict 下本地 7B 判别 2/82（上界 7.5%）、14B 0/74
   （上界 4.0%）——"排除 ≥8% 大效应"的等价表述在本地臂**更强**；
   前沿臂 7/82（上界 15.4%）不能排除 ~15% 中小效应，这正是 C 分支
   inconclusive 的定量含义，附录必须自带 CI。
2. **P1-12 张力消解（不变）**：认定任务（placebo 子集近完美）≠判别任务
   （RQ1 弱），两任务论文中显式区分。
3. **稳定判别集合修正**：原"稳定三元组 {54574, 61539, 67435}"勘正为
   **稳定二元组 {61539, 67435} + 一个跨三种子复现的弃权行为**（54574：
   vuln 恒标 vulnerable、fixed 恒弃权——v9/v10/74 三种子一致；
   14B 则判其 fixed 为 vulnerable，行为模型特异）。
