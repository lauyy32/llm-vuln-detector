## 1. 门禁（先于一切跑批；每项均有自动测试）

**G1 真实补丁完整性门禁**（对 real 与 partial 的源 diff）：
- diff 必须覆盖 vuln→fixed 的**全部**变更文件（新增/删除/重命名/修改）；
- 禁止按字典序截取文件子集；禁止从 hunk 中间截断；
- 若完整 diff 超预算：**预注册**"语义完整的最小修复"（逐 CVE 写清裁剪规则
  并保证安全机制完整）或**排除该 CVE**——二选一，不允许静默截断；
- 自动断言：注入的 real diff 含该 CVE 安全关键 hunk（对 15 子集，与
  partial_arm_construction.md 的 hunk 表对齐）。

**G2 placebo 可应用与匹配门禁**：
- placebo 在真实 vuln 文件上以真实行号构造（语义保持重构或与漏洞无关的
  生产代码变更），`git apply --check` 对每个 CVE 必须通过；
- 文件数、hunk 数、总长度与 real diff 匹配（长度比 ∈ [0.5, 2.0]）；
- 禁止任何自述性标记与教学性提示（v3 已修，v4 保留）。

**G3 全输入落盘门禁**：逐调用保存——system+user prompt 全文、注入 diff 全文、
CPG 切片、prompt/diff 的 SHA-256、模型名与 digest、Ollama/HTTP 元数据、
seed/温度/max_tokens、时间戳、运行环境 manifest（硬件/OS/版本）。

**G4 统计口径门禁**：paired_metrics 实现 **strict 主路径**（--rule strict|lenient，
默认 strict；lenient 仅供历史对照并显式标注）；文档引用脚本须过
`verify_claims.py`（新增：扫描文档中引用的脚本路径是否真实存在 +
抽查表内数字能否由入库脚本复算）。

## 2. P1-13 protocol deviation 申报（补记，非新承诺）

- **D1 弃权阈值**：预注册"单轮 abstain>20% 作废重跑"，实际两轮 48%/45% 仍保留；
  事后解释为"阈值仅针对网络故障"（故障率 3.2%）。**这是 deviation**：原规则
  未区分故障类型。处置：保留结果，双口径申报（按原规则的作废后果 vs 按
  故障子集的有效结论），后续轮次执行修正规则。
- **D2 分支定义重叠**：预注册 A 含"McNemar 不显著"析取项，与 C 的"6-9/82"
  区间重叠——7/82 + p=0.0625 同时满足 A 字面与 C 区间。处置：判读采用
  "C（方向偏 B 但不显著）"，A/C 重叠作为协议缺陷申报；后续协议分支必须互斥。
- **D3 分母措辞**："双端非 abstain 的完整对上判别统计"字面=受限分母，
  执行为分母保留 82、弃权对不贡献判别事件（更保守），已勘误留痕。

## v4.1 修正案（2026-09-06，响应第二次外部验收；未通过前禁止实现）

### A1. 新增 G0：候选补丁任务契约（先于 G1-G4）

- system/user prompt 统一称"**候选补丁**"（不再称"修复补丁（vuln→fixed diff）"）；
- 任务定义："若将候选补丁应用于给定 vulnerable 代码，是否足以消除目标漏洞"；
- 不向模型透露补丁来源、实验臂、期望标签；
- 四臂保存 prompt 快照并断言：除 candidate diff 外完全一致（自动 diff 检查）。

### A2. G2 placebo 有效性升级（apply-clean 只是必要条件）

门禁按序执行：① `git apply --check`；② 应用后语法/导入/项目相关测试通过；
③ 原漏洞 PoC 或安全回归测试仍能触发（漏洞仍存在）；④ 无 PoC 时两名技术
人员确认残余漏洞路径；⑤ 不得改动关键安全机制。防"placebo 意外修复漏洞"
的标签错误。长度匹配改为按**最终送入模型的 token 数**计，收紧至 [0.8, 1.25]，
做不到则逐例配对报告。

### A3. G1 real 完整性升级

- real diff 在 vuln 树上必须 apply-clean，且**应用后目标树与 fixed 快照逐文件
  哈希一致**（最强等价判据）；新增/删除/重命名/二进制显式处理；
- 使用"最小修复"时臂名不得称完整 real patch，须通过漏洞 oracle 并记录
  裁剪者与裁剪依据；
- 排除案例与裁剪案例分开报告；样本集变化后不得与 v3 直接比较。

### A4. 解释分支改 2×2 互斥矩阵（替代 B1-B4）

| real 相对 v3 | placebo 相对 v3 | 解释 |
|---|---|---|
| 稳定 | 稳定 | v3 对两类混淆均稳健，可升主证据 |
| 变化 | 稳定 | real 截断污染为主，v4 数字取代 real 臂 |
| 稳定 | 变化 | placebo 不可应用线索为主，旧 placebo 证据等级下调 |
| 变化 | 变化 | v3 整体不可作主证据 |

判读规则（先定，替代初版冲突定义）：
- **逐臂目标正确标签**：real 臂目标=benign；placebo/shuffled 臂目标=vulnerable；
  abstain 在主分析计为"未成功"，并单列申报（不并入任一率）。
- **逐例三分类转换表**（v3→v4）：b=v3 成功且 v4 失败；c=v3 失败且 v4 成功；
  成功率差 = (c−b)/15；全表附精确 McNemar 作辅助检验。
- **"变化"= 成功率差 |Δ| ≥ 3/15**（净变化；不称"统计显著"）——
  避免"三好三坏总 discordant 6 但净零"被误判为变化。
- **跨模型裁决**：仅当 7B 与 14B **均稳定**才可声称跨模型稳健；
  任一模型变化即不宣称总体稳健，两模型分别报告（不写"取较不利解读"）。

### A4b. token 匹配改真门禁（替代"做不到则逐例报告"）

长度比（按送入模型 token 计）超出 [0.8, 1.25] 的 CVE **重新生成或排除**，
二选一，不得带病入组；若因排除造成样本变化，报告主样本结果 +
**长度匹配子集的敏感性分析**（预先在此注册），且正文不得声称
"篇幅混淆已排除"除非全部 CVE 通过门禁。
