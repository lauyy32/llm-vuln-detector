# D4 跨模型族外部效度（P1-3）

> 关联任务：D4 多模型族对照（内部追踪「单模型族」项）
> 运行：2026-09-03 · CodeLlama:7b（Ollama 本地，temperature=0）· Devign C/C++ 函数级基准
> 对照：qwen2.5-coder:7b（同协议，v9_d2_devign）
> 产物：`cpg/ablation/seeds/v10_d4_codellama/`（results.csv + raw_llm_responses.jsonl）

## 1. 设计

在 D2 外部效度基准（Devign test split，C/C++ 函数级 vuln/benign）上，将 LLM Scorer 从
qwen2.5-coder:7b 换为 **CodeLlama:7b**（与 Qwen 不同家族，同为 7B 量级），验证「纯 LLM
函数级漏洞检测近随机」结论是否跨模型族稳健。协议完全复用 `run_d2_devign.py`：平衡采样
每类 250（共 500）、seed=42、语言无关 LocalLLMScorer、独立样本 BA/MCC/F1（McNemar 不适用，
因 Devign 非 vuln/fixed 配对）。脚本带 resume，故前期被 VRAM 争用卡顿后的样本自动续跑。

## 2. 结果

| 模型（7B） | 非弃权 n | 灵敏度 | 特异度 | **BA** | 精确率 | 召回率 | **F1** | **MCC** | 弃权率 |
|-----------|---------|--------|--------|--------|--------|--------|--------|---------|--------|
| qwen2.5-coder | 88/500 | 0.436 | 0.510 | **0.473** | 0.415 | 0.436 | **0.425** | **−0.054** | 82.4% |
| codellama | 364/500 | 0.663 | 0.432 | **0.548** | 0.511 | 0.663 | **0.577** | **+0.097** | 27.2% |

平凡基线（全判 vulnerable，50% 正类语料）：F1=0.667、BA=0.500、MCC=+0.000。

## 3. 判读（与 qwen 对照）

- **CodeLlama 并非近随机**：BA=0.548、MCC=+0.097（非弃权集 n=364，MCC 标准误≈1/√364≈0.052，
  +0.097≈1.9 SD 高于 0 → 双侧 p≈0.06，弱但可分辨的正信号）。这与 qwen 的 MCC=−0.054
  （不可分辨）形成鲜明对比。
- **但两家族均未突破平凡 F1 基线**：CodeLlama F1=0.577 < 0.667，qwen 0.425 < 0.667。
  故「纯 LLM 函数级打分在平衡语料上不优于平凡基线」这一核心结论**跨族成立**。
- **关键跨族差异：弃权率 3× 分化**（qwen 82.4% vs CodeLlama 27.2%）。qwen 对「无补丁上下文、
  仅凭函数本身」的高度不确定样本大面积 abstain；CodeLlama 更倾向于给出确定判决（且多为
  vulnerable，pred 分布 223 vuln / 141 benign / 136 abstain）。这意味着两家的非弃权子集
  **不是同一批样本**，直接 BA 比较受弃权选择混淆——必须显式声明，不能简单说"CodeLlama 更强"。
- **对 D2 原结论的修正**：原 v9 结论"纯 LLM 近随机"在 qwen 上成立，但**不能外推为跨族普适**。
  诚实表述应为：纯 LLM 函数级检测在 Devign 上**弱且模型依赖**——qwen 近随机、CodeLlama 有
  微弱正信号（MCC≈0.10），但两家族均未达到可用判别力（F1 均低于平凡基线）。

## 4. 与课题核心 claim 的关系

- D2 回答的是「LLM 打分器在通用函数级漏洞检测上的独立判别力」，与 D1「补丁边界判别」是
  **不同 claim**，不可混用为「CPG 互补/必要」证据（见 B4）。
- D4 跨族结果进一步说明：外部基准上的 LLM 表现**高度依赖模型家族与弃权策略**，不能用单一
  7B 模型（即使是本地可复现的 qwen）代表「LLM」整体。这本身是对审稿「单模型族」指控的正面回应。

## 5. 结论（D4 维度收口）

- **D4「≥2 模型族」维度达成**：qwen2.5-coder + CodeLlama 两族均在 Devign 上实跑。
- **核心外部效度结论（跨族稳健部分）**：纯 LLM 函数级漏洞打分在平衡语料上 F1 均低于平凡
  基线 0.667 → 不支持"LLM 单打独斗即可取代静态分析"的强主张。
- **需撤回/降级的部分**：原"近随机"强结论仅对 qwen 成立，CodeLlama 展露微弱正信号；
  论文须按模型族分别报告并声明弃权选择混淆，不得合并为单一"近随机"结论。
- API 前沿模型按本地模型可复现纪律有意排除（理由写入论文）。
