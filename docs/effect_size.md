> 目的：把"p≥0.05 不显著"升级为审稿人打不倒的"效应量上限 + 等价检验"表述。
> 配套：`docs/power-analysis.md`（回答"要多少样本"）；本文（回答"现有数据能排除什么效应"）。
> 计算：Clopper-Pearson 精确二项 95% 区间（双侧 + 单侧上界），无近似、无蒙特卡洛。

## 1. 方法

判别率 θ = 判定器在配对语料上正确判别（vuln 判 vulnerable 且 fixed 判 benign）的 CVE 占比。
对 LLM（随机）判别率用 Clopper-Pearson 精确区间；对 **CPGEvidence（确定性，非随机样本）**不适用 CI——
其 0/74 判别是**确定性结构事实**（CodeQL 模型下 0 个补丁切断 target 流），无抽样误差，直接陈述即可，不给 CI。

## 2. 结果（LLM 判别率，Clopper-Pearson 精确 95%）

| 7B · 74-set（3/74） | 0.041 | [0.008, 0.114] | **10.1%** |

## 3. 论文措辞（等价检验式，取代"不显著"）

> **口径声明（写进方法节一次）**：所有比例置信区间为**双侧 95% Clopper-Pearson**；等价检验（排除大效应）用**单侧 95% 上界**。二者都报，避免审稿人按双侧/单侧混算出差值。

- 双侧 95% CI：3/74→[0.008, 0.114]、3/82→[0.008, 0.103]、4/74→[0.015, 0.133]。
- 等价检验措辞（显式标"单侧"）：

> "我们没有证据支持 CPG 上下文带来补丁边界判别增益。该配对设计的**单侧 95% 置信上界**约为
> **9–12%**（3/74→10.1%、3/82→9.2%、14B 4/74→11.9%），因此**足以排除"真实判别率 ≥ ~12–15%"
> 的大效应，但不足以排除 ~5–10% 的小效应**。换言之：本设计能给出"没有大增益"的稳健结论，
> 不能给出"完全没有增益"的结论。"

- 关键升级：从"p 不显著 = 可能没效应" → "**数据排除了大效应（≥12–15%），小效应（<10%）仍在置信区间内**"。
- 与 CPG-alone 确定性结论分层表述：CPG-alone 是**结构性 0**（不靠统计、靠 flow-cut 四线闭合）；LLM 判别是**统计估计**（靠 CI 给上界）。

## 4. 对 paper 结构的影响

- RQ1（CPG-alone）：用"四线闭合 + 结构上限 6.8%"起笔，**不写 CI**（确定性事实）；
- RQ2（LLM 判别）：用上面的 CI 措辞，把"underpowered"改写成"排除了大效应、留有小效应窗口"，并引 power-analysis 说明为何窗口收不窄（语料天花板 85 对）。
- 结论不再说"CPG 无效"，而说"**CPG 的判别增益被约束在 <12% 的小效应区间内，且其机制（净化器盲区）决定了该上限来自证据层而非评分器**"。
