## 1. 目的

`RESEARCH-DESIGN.md` §8.9 把"样本量"列为尚未关闭的威胁：不一致对数 n≤3，McNemar 精确检验在该规模下不可能显著（n=3 最小 p=0.25）。本文件量化**要达到 80% 统计功效，到底需要多少 CVE 配对**，使"不显著"可被解释为"样本不足"而非"方法无效"。

## 2. 模型设定

- 单元：每个 CVE 的 vuln/fixed 配对（一对版本）。
- 方法"真实判别率" d：方法能在多大比例 CVE 上把 vuln 与 fixed 判成不同（即产生 discordant 配对）。
- 方向正确率 q：在 discordant 配对中，方法判对方向（vuln→vulnerable 且 fixed→benign）的比例。
- 检验：McNemar 单侧精确检验，α=0.05。要求功效 = P(拒绝 H0 | 方法真有判别力) ≥ 0.80。
- 所需样本量 n = CVE 配对数（版本数 = 2n）。

## 3. 所需 CVE 配对数（80% 功效）

| 真实判别率 d | q=1.0（discordant 全判对） | q=0.75 | q=0.60 |
|---|---|---|---|
| 0.05 | 140 | 540 | >1500 |
| 0.10 | 70 | 270 | >1500 |
| 0.15 | 50 | 180 | 1090 |
| 0.20 | 40 | 140 | 820 |
| 0.30 | 30 | 90 | 550 |

读法：若方法在 15% 的 CVE 上真能区分 vuln/fixed、且方向正确率 75%，需 **180 对（360 版本）**才有 80% 把握检出来；若只能区分 10%，需 **270 对（540 版本）**；若仅 5%，需 **540 对（1080 版本）**。

## 5. 结论与对评审的回应

1. **当前 McNemar 不显著是样本量注定的，不是"方法无效"的证据，但也不是"方法有效"的证据。** 在 74 配对下，即便方法真有 d≈0.04 的判别力，也需要 ~670 对（1340 版本）才有望显著——当前规模差一个数量级。
2. **D1（语料扩 ≥300 版本）是必要但不充分的。** 300 版本 = 150 对，仅够检出 d≥0.20 且 q=0.75 的强效应；要覆盖 d≈0.05–0.10 的弱效应，需扩到 **540–1080 版本**。论文必须明确：扩到 300 版本后若仍不显著，仍可能因功效不足，不能据此宣布"无效应"。
3. **功效分析应制度化**（E2）：每个 McNemar 结论旁附"在当前 n 下，能检出的真实判别率下限 d_min"，避免把"不显著"读成"无差异"。
4. 当前等效 d 上限 0.04 与 §8.1 的 BA≈随机互相印证：本课题方法在补丁边界上的真实判别力即便非零，也极弱，扩样本后能否进入可检测区间尚属开放问题（这正是 D1 的工程价值）。
